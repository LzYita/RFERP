1.1 许可方授予被许可方一项**非独占、不可转让**的软件使用许可，用于被许可方内部经营管理。

1.3 被许可方可在授权范围内增删操作账号，账号数量不设硬性上限。

1.4 未经许可方书面同意，被许可方不得：
（a）转售、出租、出借、分发本软件或本授权；

2.1 本授权为【永久授权 / 试用授权（试用期至 【日期】）/ 订阅授权（至 【日期】）】。

2.2 永久授权不因支持服务到期而停止使用；支持服务期限见第 3 条。

2.3 试用或订阅授权到期后，软件转入**只读模式**：可查询、可备份、可导出，不可写入新数据。续期后自动恢复。

3.1 支持服务期：自生效日起 **【12】** 个月。

3.2 支持方式：【电话/微信/邮件】；响应时间：【工作日 8 小时内】。

## 4. 主机与网络环境（被许可方责任）

4.1 被许可方负责主机的供电、网络、硬件与操作系统维护，并保证主机在营业时间内可用。

4.2 被许可方应：
（a）为数据目录配置独立磁盘并保留可用空间；
（b）按交付文档启用每日自动备份，并**定期把备份复制到主机之外的介质**；
（c）关闭主机睡眠/休眠，配置 DHCP 保留或固定 IP；
（d）不将数据库文件放在网络共享、U 盘或云同步目录。

4.3 许可方**不承诺**主机 7×24 小时可用，亦不对因断电、硬件故障、网络中断、操作系统或第三方软件（含杀毒软件误报）导致的停机和数据损失承担责任。

## 5. 数据与备份

5.1 业务数据的所有权归被许可方。许可方仅在提供支持所必需的范围内接触数据，且须经被许可方同意。

5.2 被许可方应自行确保备份可用。许可方提供的备份功能与恢复演练指引不构成对数据完整性的担保。

5.3 因被许可方未按第 4.2(b) 条执行异机备份而导致的数据丢失，许可方不承担责任。

7.1 许可方保证软件在交付时基本符合随附文档描述的功能。

7.2 除第 7.1 条外，软件按"现状"提供。许可方不保证软件无错误、不中断，或满足被许可方的特定业务需求。

8.1 在适用法律允许的最大范围内，许可方对因本协议或软件使用产生的间接损失、利润损失、商誉损失、数据损失不承担责任。

8.3 本条不排除依法不得排除的责任（如故意或重大过失、人身损害）。

## 9. 终止

9.1 被许可方严重违反第 1.4 条（禁止转售/反向工程/绕过授权）时，许可方有权终止本授权，已付款项不予退还。

9.2 终止后，被许可方应停止使用并删除软件；其业务数据仍归被许可方所有，可按文档导出。
