# 首次运行被拦截怎么办

> 本软件未购买商业代码签名证书。Windows 和杀毒软件会把"没见过的程序"提示出来，
> 这是**提示，不是病毒确认**。按下面处理即可；拿不准就联系支持，不要为此关闭杀毒软件。

---

## 1. 蓝色提示「Windows 已保护你的电脑」（SmartScreen）

点 **更多信息** → **仍要运行**。

## 2. 文件属性里有「解除锁定」

从微信/网页/压缩包拿到的文件会带"来自网络"标记。右键文件 → **属性** → 勾选 **解除锁定** → 确定。
或用管理员 PowerShell 对整个目录执行：

```powershell
Get-ChildItem -Path "安装包目录" -Recurse | Unblock-File
```

## 3. 杀毒软件提示「发现风险程序」/ 文件消失

选 **允许 / 添加信任 / 恢复并信任**。建议直接把两个目录加入信任区，一劳永逸：

| 杀毒软件 | 入口 |
|---|---|
| Windows Defender（Windows 安全中心） | 病毒和威胁防护设置 → 排除项 → 添加文件夹 |
| 卡巴斯基 | 设置 → 安全 → 排除项 → 指定可信文件夹 |
| 360 / 火绒 / 腾讯管家 | 设置 → 信任区 / 白名单 → 添加目录 |

要加的**两个**目录：

1. **安装目录**（默认 `C:\Program Files\RFERP`）；
2. **数据目录**（安装时选的，默认 `D:\RFERP数据`）。

> 加数据目录还有个额外好处：杀毒软件扫描数据库文件时会短暂锁住它，
> 加信任区可以避免偶发的"数据库忙"错误。

## 4. 安装脚本提示「禁止运行脚本」

用**管理员** PowerShell 执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\install-host.ps1 -Port 8080
```

`-Scope Process` 只对当前窗口生效，不改系统设置。

## 5. 核对文件是否被替换（可选但建议）

对照包内 `SHA256SUMS.txt`，对可疑文件执行：

```cmd
certutil -hashfile RFERP-server.exe SHA256
```

输出的哈希（不区分大小写）应与 `SHA256SUMS.txt` 中同名行一致。

## 6. 什么时候联系支持

- 按上面处理后仍然装不上、起不来；
- 杀毒软件**删除**了文件且恢复后再次被删（把杀毒软件名称、版本、截图发来）；
- 服务安装成功但客户端连不上（同时把 `<数据目录>\日志\rferp.log` 和
  事件查看器 → Windows 日志 → 应用程序 里来源 `RFERPServer` 的记录发来）。
